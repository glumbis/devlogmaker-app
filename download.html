Opening it the first time

Current builds are not yet code-signed, so your system shows a warning the first time you open DevlogMaker. This is expected for unsigned apps; only download DevlogMaker from this website.

Windows SmartScreen

If you see "Windows protected your PC":

  1. Click More info.
  2. Check that the app name is the DevlogMaker installer, then click Run anyway.
  3. Follow the installer. You'll find DevlogMaker in the Start menu.

macOS Gatekeeper

If macOS says the app can't be opened or the developer can't be verified:

  1. Drag DevlogMaker from the disk image into Applications.
  2. In Applications, right-click (or Control-click) DevlogMaker and choose Open, then Open again.
  3. On newer macOS versions, if there's no Open button: go to System Settings → Privacy & Security, scroll down and click Open Anyway.

After that

The app walks you through setup: add your API keys, pick a narrator voice, pick your game's folder, and fix anything the checks flag. Then choose New devlog. Using Claude Desktop? Open Settings → Claude Desktop → Connect, restart Claude Desktop and ask it to set up your game.
